# 生物医学图表分类

本文件规定如何为每个面板选择唯一的 `function_category`、`figure_type` 和 `result_template`。分类发生在面板分割之后。

## 三个维度

| 字段 | 回答的问题 | 选择原则 |
|---|---|---|
| `function_category` | 该面板承担什么科学用途 | 按研究语义而非外观选择六大类别之一 |
| `figure_type` | 它是哪一种具体图型 | 选择注册表中最具体、可证实的类型 |
| `result_template` | 结果应按哪些字段组织 | 选择能无损表达关键结果的记录模板 |

三个字段必须分别作出判断，再检查 `schemas/figure_registry_v3.json` 的兼容关系。不得仅由视觉形状自动推出科学用途；同一种条形或折线外观可能表达普通组间比较、富集、生存或剂量响应。

## 六大功能类别

1. `basic_statistics`：普通组间比较、分布、相关、时间过程和定量曲线。
2. `omics_bioinformatics`：差异特征、矩阵、降维、富集、集合和组学网络。
3. `clinical_epidemiology`：人群效应、生存、诊断、预测、流行病学和临床模型。
4. `experimental_image`：显微、组织学、条带、凝胶、流式和其他原始实验图像。
5. `workflow_mechanism`：实验流程、受试者或文献流转、机制、网络和示意图。
6. `specialized_table`：结构化表格、模型解释、信号轨迹、药效参数和其他专门结果。

类别描述科学功能，不表示数据质量或证据强度。

## 分类流程

1. 识别整幅图的图号、图注和页面。
2. 按面板标签、空间边界、模态、终点、坐标轴或实验协议分割。
3. 写出该面板要回答的科学问题。
4. 根据科学问题选择 `function_category`。
5. 根据图例、坐标、标签和图注选择最具体 `figure_type`。
6. 根据需要输出的科学字段选择 `result_template`。
7. 检查注册表兼容性和领域反例。
8. 引用支持分类的证据项，并写出简短 `rationale`。
9. 信息不足时降低置信度并创建复核建议，不得静默猜测。

## 关键辨析

- Kaplan–Meier 曲线是 `kaplan_meier`，不是普通时间过程。
- 带 IC50/EC50 或明确药效拟合的曲线是 `dose_response`，不是普通折线图。
- 富集条形或气泡图属于组学富集，不是普通组间柱状图。
- 火山图属于差异特征，不是普通散点图。
- 森林图使用临床效应记录，不能压成普通点估计图。
- 流式二维散点图按门控和群体解释，不按普通相关散点图解释。
- Western blot、凝胶和显微图按原始图像证据处理，不按柱高或像素强度自动量化。
- CONSORT、PRISMA 和实验流程使用步骤模板；机制箭头和网络边使用关系模板。
- SHAP 图属于模型解释，不是因果机制图。
- 基线特征或回归表保留表头与脚注，不按普通柱状图重构。

## 多面板与混合内容

- 图号相同不表示所有面板同类；逐面板分类。
- 一个面板内存在独立图像和定量子图时，只要可空间分割，就拆为独立面板。
- `mixed` 或 `other` 不能作为逃避分割的默认值。
- 物理上不可分的复合面板应记录多个结果块、解释不可分原因，并要求人工检查是否需要再分割。
- 面板标签可为字母、数字、组合或补充图标签；稳定内部 ID 与论文显示标签分开保存。

## 歧义处理

若候选类型依赖不可读的轴、图例或图注：

1. 保留可确定的较粗类别；
2. 不伪造具体图型；
3. 将分类置信度设为 `low` 或 `unknown`；
4. 记录候选类型及区分它们所需的最小信息；
5. 创建 `AMBIGUOUS_CLASSIFICATION` 或 `MIXED_PANEL_NOT_SEGMENTED` 复核建议。

分类置信度只反映类别映射可靠性，不代表结果真实性。
